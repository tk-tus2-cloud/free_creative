# 部門予算管理表

部門ごとの予算・実績を月次で管理するためのシンプルな Web アプリです。React + TypeScript + Vite で構築されており、データはブラウザの localStorage に保存されます（バックエンド不要）。

## 主な機能

- 部門の追加・名称変更・削除
- 部門ごとの費目（人件費、旅費交通費など）の追加・名称変更・削除
- 月次（4月〜3月）の予算・実績入力
- 予算 / 実績 / 差額 / 執行率の表示切り替え
- CSV 出力（部門別テーブル・全体サマリー）
- 全部門を横断した予算・実績の比較チャートとサマリーテーブル
- 対象年度の切り替え

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 型チェック・Lint

