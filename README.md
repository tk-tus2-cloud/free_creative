# 部門予算管理表

部門ごとの予算・実績を月次で管理するためのシンプルな Web アプリです。React + TypeScript + Vite で構築されており、データはブラウザの localStorage に保存されます（バックエンド不要）。

## 主な機能

- 部門の追加・名称変更・削除
- 部門ごとの費目（人件費、旅費交通費など）の追加・名称変更・削除
- 月次（4月〜3月）の予算・実績入力
- 予算 / 実績 / 差額 / 執行率の表示切り替え
- CSV 出力（部門別テーブル・全体サマリー）
- 全部門を横断した予算・実績の比較チャートとサマリーテーブル
- 対象年度の切り替え
- 為替影響ダッシュボード(経営層向け)
  - 通貨別の月平均レートと計画レートの比較チャート、年平均レート/計画レートの乖離表示
  - ドル円の変化率に対する各国通貨の感応度(pt)を月次実績から自動推計(手動上書き可)
  - ドル円をスライダーで動かすと、各通貨が感応度に応じて連動し、外貨建てエクスポージャーへの年間影響額(売上高・営業利益)を円換算で試算
  - 計画レート・感応度・エクスポージャー・月次実績レートは画面上で編集可能(localStorage に保存)、結果は CSV 出力可能
