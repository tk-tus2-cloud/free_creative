# 基準外賃金・所定外労働時間 推移分析

アップロードされた集計表（2025年1月〜2026年8月）をもとに、以下2つの月次推移を可視化する Web アプリです。React + TypeScript + Vite + Recharts で構築されており、データは静的に埋め込まれています（バックエンド不要）。

## 主な機能

- **基準外の構成要素の金額推移**: 基準外賃金合計を科目別（時間外手当・休出手当・特殊勤務手当・交替勤務手当・マネジメント手当・遅刻早退控除・欠勤控除・.SF用減額）に分解した積み上げ棒グラフ＋合計の推移線
- **所定外時間の推移**: 所定外労働時間を組織区分別（国内BU・海外BU・コーポレート・各センター・関係会社計）に分解した積み上げ棒グラフ＋合計の推移線
- 各グラフに対応するデータテーブルと CSV 出力
- ダークモード対応

## データソース

`src/data/trendData.ts` にアップロードされた Excel ファイル（`⇒基準外賃金` ワークブックの `PIVOT_科目別` シートおよび `所定外労働時間推移` シート）から集計した数値を格納しています。各月の構成要素の合計は元データの合計行と一致することを確認済みです。
