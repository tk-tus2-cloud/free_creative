# デジタル組織の再設計案 ― 役割・人の再配置・移行プラン

## 1. 診断：3つの問題は独立ではなく「連鎖」している

| 階層 | 現状 | 組織への影響 |
|---|---|---|
| 執行役員 | 前向き・アイデア寄り・抽象的 | アイデアが構造化されず現場に降る。優先順位が定まらず、現場は「また新しい話が来た」と疲弊 |
| 部長 | 専門家型・ネガティブ・後ろ向き | 執行役員のアイデアの「防波堤」になっているが、代案を示さないため方針が真空化。マネジメント（育成・評価・組織運営）が実質不在 |
| TLの1名 | 能力は高いが、人の囲い込み・嫉妬・僻み・悪口。メンバーからクレーム | マネジメント不在の真空地帯で「属人王国」が形成・放置されている。最も危険なのは優秀な若手から辞めること |

**本質：** 執行役員は「ビジョンはあるが実行管理をしない」、部長は「専門性はあるが組織運営をしない」、TLの1名は「能力はあるが人を預けられない」。つまり**「経営の言葉を現場の実行に翻訳する機能」と「人と組織を健全に保つ機能」の2つが、誰の職務にもなっていない**。個人を責めても解決しない。役割の設計と登用基準を変える。

## 2. 設計原則（5つ）

1. **人から設計しない。機能から設計する。** 今の顔ぶれに合わせて箱を作ると、次の異動で崩れる。必要な機能を先に定義し、人を当てる。
2. **マネジメントと専門性を複線化する（デュアルラダー）。** 「偉くなる＝部下を持つ」をやめる。専門性で処遇される「専門職ライン」を作ることで、マネジメント不適格者からラインを外しても、処遇と名誉を落とさずに済む。これが今回の人事の鍵。
3. **人材はチームの所有物ではなく、部の資産。** アサイン・育成・異動はTLの一存ではなく部のタレントボードで決める。これで「囲い込み」は構造的に成立しなくなる。
4. **アイデアは1つのファネルで受ける。** 執行役員のアイデアを殺さず、しかし現場に直撃させない。「テーマ提案→企画機能で構造化→優先順位付け→リソース割当」の単一経路を敷く。
5. **行動（バリュー）をライン登用の必須要件にする。** 成果・能力がどれほど高くても、人を壊す行動がある者にピープルマネジメントは任せない。これを明文化した基準にする（属人判断にしない）。

## 3. 目指す組織の形

```
執行役員（デジタル担当）
│  役割：ビジョン・対経営/対外・リソース獲得・テーマの「種」の提供
│  ルール：アイデアは企画ファネルへ（現場への直接指示は封印）
│
├─ 部長（組織運営専任・新任）
│   役割：実行管理・人と組織の健全性・タレントボード議長
│   ※マネジメントを「専任の仕事」として遂行できる人材を登用（内部登用 or 外部採用）
│
│   ├─ 企画・PMO機能（翻訳装置）
│   │    執行役員のアイデアをテーマ化し、優先順位・投資判断・進捗管理に落とす
│   │
│   ├─ チームA ── TL（ライン管理職）
│   ├─ チームB ── TL（ライン管理職）
│   ├─ チームC ── TL（ライン管理職・新任登用）
│   │
│   └─ タレントボード（部長直轄）
│        アサイン・ローテーション・育成・登用を部として決定
│
└─ 首席専門職（チーフエキスパート）＝現部長の受け皿
     役割：技術判断・投資案件の批判的レビュー（リスクデューデリ）・後進の技術指導
     ラインなし。専門職ラインの最上位として処遇維持

  プリンシパル（高度専門職）＝問題TLの受け皿
     役割：最難度テーマの個人貢献者（IC）。直属部下なし
     専門職ラインとして処遇維持。タレントボードの構成員にはしない
```

**ポイントは「2つの受け皿」を先に作ること。** 現部長と問題TLはどちらも「専門能力は高いがマネジメントに不適」という同型の問題。デュアルラダーを制度として先に敷けば、2人とも**降格ではなく「専門職ラインへの登用」として異動**でき、本人の尊厳と処遇を守りながらラインから外せる。

## 4. 人の再配置案

| 対象 | 現在 | 提案 | 狙い | リスクと手当て |
|---|---|---|---|---|
| 執行役員 | 抽象的なアイデアが現場に直撃 | 役割は変えず「ルール」を変える：テーマ提案は企画ファネル経由に一本化。四半期ごとの優先順位レビューの議長を担ってもらう | 前向きさとアイデアは組織の資産。殺さずに「構造化して実行に乗せる装置」を付ける | 面子を潰さないこと。「アイデアを実現するための装置」として提案する（制限ではなく実現支援の建付け） |
| 部長 | マネジメント不全・後ろ向き発言で方針真空 | **首席専門職へ横滑り**。技術判断と投資案件の批判的レビューを公式な職務にする。組織運営は新部長へ | 「後ろ向き」は役割を与えれば「リスク感知能力」という資産になる。制度化されたレビュー役なら批判が組織貢献に変わる | 本人が「外された」と受け取るリスク→専門職ライン最上位としての処遇・呼称を用意。移行は執行役員から直接、敬意をもって伝える |
| 新部長 | （不在の機能） | 内部登用（残り2TLのうちマネジメント適性のある者）または外部採用。**「専門で一番」ではなく「人と実行の管理ができる」を要件に** | マネジメントを専任の仕事として遂行する層を初めて作る | 内部登用ならTL層が1枚薄くなる→後述の新任TL登用とセット。外部なら文化理解に6ヶ月見込む |
| 問題TL | 能力は高いが囲い込み・嫉妬・悪口でクレーム | **2段階で対応。①事実確認と行動期待の明示（後述）→②改善がなければプリンシパル（ラインなし高度専門職）へ転換**。育成・評価・アサイン権限をすべて外す | 能力は使い続けるが、人は預けない。専門職転換なら処遇を落とさず実現可能 | 離職リスク（能力が高いだけに）→プリンシパルを「選ばれた者の職位」として設計し名誉を保つ。囲われていたメンバーのケア（スキップ1on1）を並行実施。**ハラスメントに該当する事実が確認されれば、この案とは別に人事プロセスで対応（順番を混同しない）** |
| 残り2TL | （記載情報なし） | アセスメント（360度・メンバーサーベイ）の上、1名は新部長候補、チームCには次世代の新任TLを登用 | 「行動要件を満たす者がラインに就く」という新基準の最初の実例を作る | 新任TLには企画・PMOとタレントボードが後見に付く |
| メンバー層 | クレームを上げている状態 | タレントボード発足後、希望調査とローテーションを実施。囲い込まれていた人材から優先的に動かす | 「声を上げたら組織が変わった」という成功体験が、その後のエンゲージメントを決める | 異動＝問題TLへの当てつけに見えないよう、部全体のローテーション制度として実施 |

## 5. 「囲い込み・嫉妬・悪口」を構造的に無効化する仕組み

個人の性格は変えられないが、**その行動が成立する構造は潰せる。**

| 仕組み | 内容 | 潰せる行動 |
|---|---|---|
| タレントボード | アサイン・育成・登用・ローテーションを部長直轄の会議体で決定。TLは意見は言えるが決定権はない | 囲い込み（人事権の私物化） |
| 定期ローテーション | 2〜3年でのチーム間異動を原則化。スキルマップで部内の能力を可視化 | 属人化・「あの人しか知らない」の意図的温存 |
| 360度評価＋バリュー行動評価 | マネジメント層は部下・同僚からの評価を昇格・登用・継続の必須要件にする | 悪口・威圧（上にだけ良い顔をする行動が通用しなくなる） |
| スキップレベル1on1 | 部長がTLを飛ばしてメンバーと定期対話。退職・異動理由も部長が直接把握 | クレームの握り潰し・情報の遮断 |
| エンゲージメントサーベイ（チーム別） | 四半期ごと。チーム別スコアをマネジメント評価に連動 | 「成果は出ているから問題ない」という見過ごし |
| 企画ファネル（単一経路） | テーマ・投資はすべて企画機能で構造化してから着手 | 執行役員の思いつき直撃／TLによる個人的なテーマ抱え込み |

## 6. 移行ロードマップ

**フェーズ1：事実と土台（〜90日）**
- メンバーサーベイ＋スキップレベル1on1で、クレームの事実確認（伝聞で人事を動かさない。ここが全ての正当性の土台）
- 問題TLに対し、行動期待を書面で明示し、改善期間を設定（評価者は部長ではなく執行役員＋人事同席）
- 企画ファネルの運用開始（執行役員と合意）
- デュアルラダー（専門職ライン）制度の設計着手

**フェーズ2：形を変える（3〜6ヶ月）**
- 専門職ライン制度化 → 現部長を首席専門職へ、新部長体制発足
- タレントボード発足、スキルマップ整備、360度評価の導入
- 問題TLの改善判定 → 改善なければプリンシパルへ転換（ライン権限を外す）
- 新任TL登用（新基準での最初の登用実例）

**フェーズ3：定着（6〜12ヶ月）**
- 第1回ローテーション実施
- サーベイスコア・離職率・登用実績で効果検証
- 執行役員のテーマファネル運用を振り返り、投資優先順位プロセスとして定常化

## 7. 実行上の留意点（重要）

1. **順番を間違えない。** 「制度（受け皿）→事実確認→本人への期待明示→役割変更」の順。制度がないまま問題TLだけを動かすと「個人攻撃」になり、組織が委縮する。制度を先に作れば「全員に適用される新しいルール」になる。
2. **クレームは必ず検証する。** メンバーの声が事実か、複数ソースで確認してから動く。仮にハラスメント該当なら、組織設計とは別の人事・コンプライアンスプロセスで扱う。
3. **能力の高い人間を敵にしない設計。** 現部長も問題TLも、追い出すのではなく「専門性で貢献する椅子」を用意する。それでも行動が改まらない場合に限り、部外への異動を選択肢にする（その判断基準も事前に明文化しておく）。
4. **最初に守るべきはメンバー層。** この状況で最初に辞めるのは、囲い込まれている優秀な若手。フェーズ1のスキップ1on1とサーベイは、彼らへの「見ている」というシグナルでもある。
