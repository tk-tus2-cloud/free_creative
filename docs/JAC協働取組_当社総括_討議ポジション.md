# JACとの協働取組 検証 — 当社総括と本日のゴール(討議ポジション v3)

**位置づけ**: 2026年7月30日 経営執行会議 フリーディスカッション(論点1〜4)に対する当社側の討議ポジション
**基準日**: 2026年7月24日(市場数値はIR最終確認前の概算を含む)

---

## 0. 全体を貫く一つの式

> **株価 = 利益 × 信頼**
> (信頼 = 市場が「この利益は続き、伸びる」と信じる度合い。数字の上では評価倍率)

この2年の成績を、三つの相手と比べて採点する:

| 比較相手 | 結果 | 判定 |
|---|---|---|
| JACがいなかった場合の自社 | 利益2割超増、決める速度と測る規律が定着 | **前進** |
| 業界(花王・ユニ・チャーム) | 分割調整後で花王ほぼ横ばい、ユニ・チャーム大幅安に対し+7% | **健闘** |
| 市場(TOPIX)と当初目標 | 市場+51%に対し+7%。倍率は目標29倍に対し16.1倍と、起点19倍から低下 | **未達** |

ここで重要なのは、**「業界内では健闘」が慰めにならない**ことである。業界ごと市場から取り残されているからだ。最優等生の花王でさえ23.3倍、ユニ・チャームは19.3倍 — **国内トイレタリーという物語そのものに、市場はもう高い倍率を払っていない**。

∴ 2年間の総括は一行で書ける — **「利益は買えた。信頼はまだ買えていない。そして信頼は、今いる業界の中には売っていない。」**

## 1. 座標軸: 目標29倍は「業界の外」にしかない

JACと合意した倍率目標(29倍)は、トイレタリー業界の倍率帯ではない。**�ルスケア・コンシューマーヘルス企業の倍率帯**である。かつて当社が高い評価を得ていた時期(16〜19年)に市場が買っていたのは、洗剤の会社ではなく「予防歯科・ヘルスケアの成長株」という物語だった。

つまりJAC提案の本質は、最初から**「業界を乗り換える」提案**だったのであり、この2年の未達とは「コスト改善の未達」ではなく**「越境の未達」**である。この座標軸で業界を見渡すと:

- **花王**は資本市場対応を加速(株式分割による投資家層拡大など)し、業界内でも「市場との向き合い方」で先行し始めた
- **小林製薬**は外部株主の関与下で再評価が進んだとされる — **業界内でも、外圧を再評価に転換できた実例が既にある**
- **ユニ・チャーム**は海外(中国)依存の逆回転で大幅安 — 越境は「どこへ」を誤ると倍率をむしろ壊す、という教訓
- そして市場には、当社の「あるべき株価」を公言する第三者が既に存在する — 当社が越境の物語を語らなければ、**外部が代わりに物語(再編・還元)を語り始める**

**帰結: 競合との闘いの主戦場は、店頭のシェアではなく「どちらが先に、市場が信じる次の物語に乗り換えるか」に移っている。** 当社の+7%と16.1倍は、この乗り換え競争における現在順位である。

## 2. 総括(診断): なぜ信頼が動かないのか — 三つの「未決定」

市場が企業を信じる材料は三つしかない。**「何で伸びるのか(物語)」「そのために何を犠牲にできるのか(覚悟)」「大株主はいつどう出ていくのか(見通し)」。** 当社はこの三つを決めていない。

**未決定① 物語 — どの業界の会社として評価されたいかを、選び切っていない**
正確に言えば、物語の未決定とは「業界の物語(国内成熟×コスト改善)から、どの越境の物語(ヘルスケア×海外)へ移るか」の未決定である。その越境の中核と自ら位置づけた領域の推進体制を、担い手と権限を曖昧にしたまま止めた。削る話は進み、乗り換える話が止まっている — 倍率が業界平均にすら届かない第一の理由。

**未決定② 覚悟 — どこまで踏み込むかの線を、引いていない**
目標達成のために何を犠牲にし、何は守るのか。線引きなき目標は、市場には約束ではなく願望に見える。花王・小林製薬の例が示す通り、市場は「痛みを引き受けた会社」から順に倍率を返している — 第二の理由。

**未決定③ 見通し — 関係の終わり方を、設計していない**
パートナーシップに期限も成功条件もなく、「いつ大量の株が出てくるか分からない」状態が続く。出口の見えない大株主を抱えた銘柄に投資家は高い倍率を払わない。しかも「あるべき株価」を公言する第三者がいる以上、無防備な出口は業界内の再評価事例とは逆向きの、最も高くつく形で使われ得る — 第三の理由。

**診断の帰結**: 三つとも相手の能力の問題ではなく**当社の「未決定」**である。外部の圧力は、当社が受け皿を用意した場所(利益)でだけ機能し、用意しなかった場所(物語)では機能しなかった。ゆえに本日の主語はJACではなく当社、動詞は「してもらう」ではなく**「決める」**。

## 4. 本日のゴール — 論点1〜4への当社ポジション

### 論点1: JACとの取組の何を変えるか — 「圧力の向き」を、業界の外へ向ける

この2年、圧力は利益(削る・締める・測る)に向いて効いた。しかし**信頼はコスト削減では買えず、ましてや業界の中には売っていない**。次の1年半、同じ圧力を「越境の実装」へ向け直す。

- **テーマの選定基準を「業界の外に出るか」に置く**: ①ヘルスケアへの越境の中核(オーラルケアの成長設計)②海外収益構造の作り直し — ユニ・チャームの教訓を踏まえ「どこで・どの深さで」を選び直す ③事業の入れ替え — 買うだけでなく、業界の物語に留まる事業を売る・やめる。この3つに集中し、倍率に効かないテーマからは撤退する。活動の総量ではなく**圧力の密度**を上げる。
- **関係の質を変える**: 提案を受ける関係から、決めたことをやり切らせる関係へ。議題の主導権は当社が握り、越境の物語に資さない持ち込みは入り口で断る。
- **計器を替える**: 成果測定を「利益の増分」から「**同業(花王)との倍率差の縮小、そしてヘルスケア企業群との倍率差**」へ。どの業界の会社として値付けされているかを常時計測する — 乗り換え競争の順位表を自分で持つ。

### 論点2: 自社内で変えるべきことは何か — 「決める側」の再建

外部の圧力は、当社が受け皿を用意した場所でだけ機能した。制約条件は相手の能力ではなく、当社の決定の速さと明確さである。

- **物語に名前を付ける**: 越境の中核テーマに、責任者の名前・委譲された権限・専用の予算を紐づけて再起動する。あわせて**「どの土俵で・誰に勝つのか」の勝ち筋を競合起点で設計する** — 越境先には花王もグローバル大手もいる。土俵の定義なき越境は、より強い相手の庭に裸で入ることと同じ。
- **覚悟の線を引く**: 「目標のためにここまではやる、ここからはやらない」を取締役会の決定として言語化する。市場は痛みを引き受けた会社から順に倍率を返している — この一文が信頼の値段を変える。
- **時間軸を二重にする**: 目の前の目標に全員を張り付ける現体制は、次の物語を作る人間をゼロにしている。「次の物語」の担当を今の執行から切り離して置く。
- **通信簿を自分で書かない**: 推進部門の自己検証は「成果も課題もあった」に着地する。外の目盛り(市場対比・同業対比の倍率差)での採点を併記させる。

### 論点3: JACと何を合意すべきか — 「別れ方」を先に決める

関係の価値を最後に決めるのは、始め方ではなく終わり方である。業界には両方の実例が既にある — 外圧を再評価に転換した例と、外部に物語を奪われた例と。どちら側に立つかは、出口の設計で決まる。

- **成功と失敗を定義する**: 利益の指標と倍率の指標(同業との差)を両方置き、達成・未達それぞれで関係を「続ける・縮める・終える」の基準ごと文書化する。
- **退出の段取りを平時に設計する**: いつ・どう売るか、市場にどう説明するか。「あるべき株価」を公言する第三者が存在する以上、出口局面は当社が最も攻められやすい瞬間になる。**段取りのない別れは2年の成果を一日で失わせ、逆に出口の透明化はそれ自体が倍率の重石を外す施策**である。
- **「どの業界の倍率で評価されるべきか」の主張を共同で作る**: 公言された「あるべき株価」との差分を、越境の物語の実装計画と紐づけて要因分解し、そのまま市場への説明の背骨にする。資本市場のプロである相手に最も期待すべき成果物。
- **土台の規律を「お願い」から「合意」へ**: 情報の取り扱い、担当者の継続性、断った案件の再持ち込み — 信頼の土台こそ文書で縛る。

### 論点4: 変えなくてもよいことは何か — 「発電機」は残す、電源を切り替える

利益を2割動かした装置 — 短いサイクルの業績管理、任せて速く決める事業運営、開示前に外の目を通す習慣、目標から逆算する文化 — は確かな遺産であり、解体しない。**これは業界内で当社が先んじて手に入れた経営インフラであり、競合対比の無形資産**である。

ただし、動力源が外部にある限りそれは資産ではなく借り物。1年半後に相手がいなくなっても回り続けるよう、期限を切って人と仕組みに移し替える(自家発電化)。同時に、増築した会議と報告は棚卸しし、**残すものの宣言と壊すものの宣言を常に一対で出す** — 現場の疲弊と形骸化への最も効く手当。
