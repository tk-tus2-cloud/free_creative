# JACとの協働取組 検証 — 当社総括と本日のゴール(討議ポジション v2)

**位置づけ**: 2026年7月30日 経営執行会議 フリーディスカッション(論点1〜4)に対する当社側の討議ポジション
**基準日**: 2026年7月24日(市場数値はIR最終確認前の概算を含む)

---

## 0. 全体を貫く一つの式

> **株価 = 利益 × 信頼**
> (信頼 = 市場が「この利益は続き、伸びる」と信じる度合い。数字の上では評価倍率)

この2年の総括は、すべてこの式の上に載る。

- **利益**: 2割超伸びた。外部の圧力は、効いた。
- **信頼**: 19倍 → 16.1倍。目指した29倍と逆方向に動いた。
- **株価**: +7%(市場全体は+51%)。**利益の増分を、信頼の減分が食い潰した残高**である。

つまり2年間の成績は一行で書ける — **「利益は買えた。信頼はまだ買えていない。」**
本日の議論は、この「信頼の未払い」をどう回収するかに絞られる。

---

## 1. 総括(診断): なぜ信頼だけが動かないのか — 三つの「未決定」

市場が企業を信じるために必要な材料は、突き詰めれば三つしかない。**「この会社は何で伸びるのか(物語)」「そのために何を犠牲にできるのか(覚悟)」「大株主はいつどう出ていくのか(見通し)」。** 当社はこの三つを、まだ決めていない。

**未決定① 物語 — 何で伸びるかを、選び切っていない**
成長の中核と自ら位置づけた領域の推進体制を、担い手と権限を曖昧にしたまま立ち上げられずに止めた。削る話は進み、伸ばす話が止まっている。市場は「何で伸びるか」を語れない会社の将来を割り引けない — 倍率が下がった第一の理由。

**未決定② 覚悟 — どこまで踏み込むかの線を、引いていない**
目標達成のために何を犠牲にし、何は守るのか。この線引きを先送りしたまま目標だけが掲げられている。**線引きのない目標は、市場には約束ではなく願望に見える** — 倍率が下がった第二の理由。

**未決定③ 見通し — 関係の終わり方を、設計していない**
パートナーシップに期限も成功条件もなく、「いつ大量の株が市場に出てくるか分からない」状態が続いている。投資家は、出口の見えない大株主を抱えた銘柄に高い倍率を払わない — 倍率が下がった第三の理由。しかも市場には既に「あるべき株価」を公言する第三者がおり、無防備な出口は最も高くつく。

**診断の帰結**: 三つとも、相手の能力の問題ではなく**当社の「未決定」**である。実際、外部の圧力は当社が受け皿を用意した場所(利益)でだけ機能し、用意しなかった場所(物語)では機能しなかった。したがって本日の議論の主語はJACではなく当社、動詞は「してもらう」ではなく**「決める」**である。

## 3. 本日のゴール — 論点1〜4への当社ポジション

### 論点1: JACとの取組の何を変えるか — 「圧力の向き」を変える

この2年、JACの圧力は利益に向いていた — 削る・締める・測る。効いた。しかし**信頼はコスト削減では買えない**。次の1年半、同じ圧力を「物語の実装」へ向け直す。

- **対象を絞る**: 倍率を動かす少数のテーマ(成長の中核領域の再起動、海外収益構造の作り直し、事業の入れ替え=買うだけでなく売る・やめるを含む)に集中し、信頼に効かないテーマからは撤退する。活動の総量ではなく、**圧力の密度**を上げる。
- **関係の質を変える**: 提案を受ける関係から、決めたことをやり切らせる関係へ。議題の主導権は当社が握り、当社の物語に資さない持ち込みは入り口で断る。
- **計器を替える**: 成果の測定を「利益がいくら増えたか」から「**同業との倍率の差がいくら縮んだか**」へ。圧力の向きを変えたなら、メーターも替えなければ操縦できない。

### 論点2: 自社内で変えるべきことは何か — 「決める側」の再建

2年間の最大の発見は、**外部の圧力は、当社が受け皿を用意した場所でだけ機能した**ということ。制約条件は相手の能力ではなく、当社の決定の速さと明確さである。

- **物語に名前を付ける**: 成長の中核テーマに、責任者の名前・委譲された権限・専用の予算を紐づけて再起動する。誰の仕事か言えない戦略は、戦略ではなく願望。
- **覚悟の線を引く**: 「目標のためにここまではやる、ここからはやらない」を取締役会の決定として言語化する。この一文が言えるだけで、目標は願望から約束に変わり、**信頼の値段が変わる**。
- **時間軸を二重にする**: 目の前の目標に全員を張り付ける現体制は、その先の物語を作る人間をゼロにしている。「次の物語」の担当を、今の執行から切り離して置く。
- **通信簿を自分で書かない**: 推進した部門が検証も行う構造では、結論は必ず「成果も課題もあった」に着地する。外の目盛り(市場対比の株価、同業対比の倍率)での採点を併記させる。

### 論点3: JACと何を合意すべきか — 「別れ方」を先に決める

関係の価値を最後に決めるのは、始め方ではなく終わり方である。

- **成功と失敗を定義する**: 中間指標(利益)と倍率の指標(信頼)を両方置き、達成・未達それぞれの場合に関係を「続ける・縮める・終える」の判断基準ごと文書にする。曖昧な継続にも、唐突な終了にも耐えられる形にしておく。
- **退出の段取りを平時に設計する**: いつ・どう売るか、市場にどう説明するか。「あるべき株価」を公言する第三者が存在する以上、出口の局面は当社が最も攻められやすい瞬間になる。**段取りのない別れは、2年の成果を一日で失わせ得る。逆に、出口の透明化はそれ自体が倍率の重石を外す施策**である。
- **土台の規律を「お願い」から「合意」へ**: 情報の取り扱い、担当者の継続性、一度断った案件の再持ち込み — 信頼関係の土台こそ、紳士協定ではなく文書で縛る。

### 論点4: 変えなくてもよいことは何か — 「発電機」は残す、電源を切り替える

利益を2割動かした装置 — 短いサイクルの業績管理、任せて速く決める事業運営、開示の前に外の目を通す習慣、目標から逆算する文化 — は、この協働の確かな遺産であり、解体してはならない。

ただし、**動力源が外部にある限り、それは資産ではなく借り物**である。1年半後に相手がいなくなっても同じ規律が回り続けるよう、人と仕組みに移し替える(自家発電化)。期限を切って移管計画を作り、「外部電源を抜いても止まらないこと」を検証して初めて「維持」と呼ぶ。
同時に、増築を重ねた会議と報告は棚卸しする — **残すものの宣言と、壊すものの宣言は常に一対**。これが現場の疲弊と、取組の形骸化への最も効く手当である。

## 4. 結び — 8月に持ち込むのは「検証結果」ではなく「決定事項」

1. **物語の実装体制**(責任者の名前・権限・予算) — 未決定①への答え
2. **覚悟の線引き**(取締役会の決定として) — 未決定②への答え
3. **別れ方の合意**(成功条件・見直し基準・退出の段取り) — 未決定③への答え
4. **自家発電化の期限と廃止リスト** — 遺産を借り物で終わらせないために

> この2年で、外の力を借りれば利益が動くことは証明された。
> 次の1年半で証明すべきは、**その利益を市場の信頼に換える力が、当社自身にあること**。
> 利益は買えた。信頼はまだ買えていない — そして**信頼だけは、外注できない**。
