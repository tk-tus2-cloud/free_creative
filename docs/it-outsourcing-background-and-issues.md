# IT運用・保守アウトソーシング検討 — 背景・課題の洗い出し（戦略コンサル視点）

作成日: 2026-08-10
対象: ライオン株式会社 IT運用・保守アウトソーシング検討（Vision2030 2nd Stage「収益力強靭化」文脈）

---

## 1. 現行スライド（背景と狙い）の評価

### 十分にカバーできている点
- 外部ベンダによるブラックボックス化（責任分界・工数の不可視化）
- デジタル戦略部社員の業務過多と隠れ工数（シャドーワーク）
- 属人化による事業継続リスク
- 新運用領域（データ基盤・BI・生成AI）への対応
- ゴール4点（コスト最適化／業務高度化／品質向上／AI活用）

### 欠けている・弱い点（経営層を動かすために必要な軸）
1. **人材・労務の構造的リスク**が一切触れられていない
   - 運用・保守の専門人材を採用していない＝内製維持の前提がそもそも崩れている、という最も強い論拠が抜けている
   - メンタルヘルス不調者の発生は「安全配慮義務」に関わる経営リスクであり、コスト論より優先度が高い
2. **定量インパクトの欠如**
   - 「コスト最適化」と言いながら、現状コスト（TCO）・隠れコストの規模感が示されていない
3. **やらない場合のリスク（Cost of Inaction）**が明示されていない
   - 現状維持シナリオで何が起きるかの対比がないと、投資判断の緊急性が伝わらない

**結論: 「IT部門の困りごと」としては十分だが、「経営課題」として通すには不十分。** 以下の観点を追加すべき。

## 2. 追加すべき背景・課題（影響度×コストの大きい順に整理）

### A. 人材・組織リスク（最優先で追加すべき軸）

| # | 課題 | 経営インパクト |
|---|------|--------------|
| A-1 | **運用・保守専門人材を採用していない** — 内製で品質を維持する前提が構造的に成立していない。IT人材の獲得競争は激化しており（消費財メーカーはIT専門職の処遇・キャリアで専業SIer/事業会社DX部門に劣後）、今後の採用も現実的でない | 内製継続シナリオの実現可能性そのものを否定する根拠 |
| A-2 | **採用・育成の投資が回収できない** — 中途採用1名あたり紹介手数料・工数で数百万円、戦力化まで1〜2年。育成しても運用業務のキャリア魅力が低く離職しやすい。「採って・育てて・辞められる」サイクルで投資が消失 | 採用費＋育成期間の人件費＋離職時の再採用費が反復発生 |
| A-3 | **メンタルヘルス不調者の発生** — 障害対応・夜間休日オンコール・問い合わせ集中による心理的負荷。休職者1名あたりのコスト（休職中給与＋代替要員＋復職支援）は年収の1〜3倍と言われる。安全配慮義務（労働契約法5条）違反となれば労務リスク・レピュテーションリスクに直結 | コストに加え、法務・ES・採用ブランドへの波及。経営報告事項 |
| A-4 | **キャリアパスの不在によるモチベーション低下** — デジ戦社員が定常運用に固定されると、DX企画・データ活用など本来やるべき仕事に移れず、優秀層から離職する逆選抜が起きる | 組織能力の空洞化。Vision2030推進体制の毀損 |
| A-5 | **ナレッジの個人依存（属人化）の時限性** — シニア社員の定年・異動が近づくほど、移管コストは指数的に増加。「動けるうちに文書化・移管する」last chance の議論 | 退職後の有事対応不能＝事業停止リスク |

### B. コスト構造の課題

| # | 課題 | 経営インパクト |
|---|------|--------------|
| B-1 | **TCOが把握できていない** — ベンダ費用（見えるコスト）に加え、デジ戦社員の運用従事工数・手戻り対応・シャドーワークを人件費換算した「真の運用コスト」が不明。最適化以前に測定ができていない | アウトソーシングの投資対効果を判断する分母が存在しない |
| B-2 | **固定費構造** — 内製人員＋個別ベンダ契約は業務量が減っても減らない。従量・成果ベースの外部化により変動費化し、収益力強靭化（限界利益率改善）に直接寄与 | Vision2030のメインテーマと直結する論点 |
| B-3 | **マルチベンダの重複・割高構造** — 複数ベンダへの個別発注はスケールメリットが働かず、ベンダ間調整コスト（会議・仕様連携・責任の押し付け合い）をライオン側が負担している | 統合発注・SIAM型マネジメントで10〜30%削減が業界相場 |
| B-4 | **障害時のビジネス機会損失** — 基幹系・受発注・物流系システムの停止は、売上機会損失・納品遅延ペナルティ・小売取引先への信頼毀損に直結。属人運用のままでは復旧時間（MTTR）が個人の稼働に依存 | 「1時間止まるといくら失うか」を試算し提示すべき最大のリスク項目 |
| B-5 | **手戻り・品質補完の隠れ工数** — ベンダ成果物のレビュー・補完・再依頼のコストが契約金額の外側で発生（スライドに記載あるが、金額換算されていない） | FTE換算で可視化すると説得力が跳ね上がる |

### C. 品質・ガバナンスの課題

| # | 課題 | 経営インパクト |
|---|------|--------------|
| C-1 | **SLA/KPIが未整備で品質を測定・比較できない** — 「品質向上」を掲げても、現状のインシデント件数・解決時間・満足度のベースラインがなければ改善を証明できない | アウトソーシング後のベンダ統制の前提条件 |
| C-2 | **セキュリティ・インシデント対応力の不足** — ランサムウェア等の脅威に対し、属人・分散運用では検知〜初動〜復旧の統制が効かない。製造業では工場系（OT）を含めた24/365監視が標準になりつつある | 情報漏えい・操業停止時の損失は運用コスト最適化の桁を超える |
| C-3 | **IT統制・監査対応の負荷** — J-SOX ITGC、アクセス権管理、変更管理の証跡が属人運用では担保しにくく、監査指摘・是正対応の工数が毎年発生 | 上場企業としてのコンプライアンスコスト |
| C-4 | **EOL・レガシー資産の塩漬け** — 運用に追われ、サポート切れOS/ミドルウェアの計画的更改が後手に回る（いわゆる「2025年の崖」の実態）。技術的負債が保守コストとリスクを毎年押し上げる | 放置コストは年率で増加。モダナイゼーションの推進余力確保が必要 |

### D. 将来対応・成長制約の課題

| # | 課題 | 経営インパクト |
|---|------|--------------|
| D-1 | **DX推進のボトルネック化** — デジ戦部の工数が運用に吸われる限り、データ活用・AI活用など攻めのIT投資の実行速度が上がらない。運用外部化は「コスト削減」ではなく「成長投資の原資（人・時間）の捻出」と位置づけるべき | Vision2030の実行速度そのもの |
| D-2 | **24/365・グローバル対応の要求増** — EC・海外事業・サプライチェーンのデジタル化に伴い、営業時間内対応を前提とした現体制では追随できない | 内製でのシフト勤務体制構築は採用面から非現実的（A-1と連動） |
| D-3 | **BCP/DRの実効性不足** — 属人運用では災害・パンデミック時に「その人が出社できなければ復旧できない」状態。訓練・手順書整備も後回しになりがち | 有事の事業継続能力＝取引先・株主への説明責任 |

## 3. スライドへの反映提案

### 背景・課題の再構成（3本柱 → 4本柱へ）

現行の3項目（ブラックボックス化／業務過多／新領域対応）に、**「人材・労務の構造的リスク」を第1項目として追加**することを推奨。

> **✓ 運用・保守を内製で維持する前提の崩壊（人材・労務リスク）**
> - 運用・保守の専門人材は採用しておらず、今後の採用市場環境からも内製での体制維持は現実的でない
> - 採用・育成に多大な時間とコストを投じても、キャリア魅力の低さから定着せず投資が回収できていない
> - 障害対応・オンコール等の負荷によりメンタルヘルス不調者が発生しており、安全配慮の観点からも現体制の継続は経営リスク

### 「やらない場合」の対比スライドを1枚追加

| 観点 | 現状維持シナリオ | アウトソーシング実行シナリオ |
|------|----------------|---------------------------|
| 人材 | 採用難・離職・不調者の反復、体制の先細り | プロ人材プールの活用、社員は企画・統制に集中 |
| コスト | 固定費＋隠れ工数が不可視のまま増加 | TCO可視化 → 変動費化 → 継続的削減 |
| 品質 | 属人依存、SLA無し、測定不能 | SLA/KPIによる測定・改善サイクル |
| リスク | 退職・障害・監査・セキュリティが顕在化待ち | 体制・手順・証跡で構造的に低減 |

### 定量化して添えるべき数字（概算で可）

1. 現状TCO: ベンダ費用 ＋ デジ戦社員の運用従事工数×人件費単価（FTE換算）
2. 隠れコスト: 手戻り・補完・調整工数のFTE換算
3. 人材コスト: 採用費・育成期間人件費・休職/離職時コストの実績
4. 障害インパクト: 主要システム停止1時間あたりの売上・業務影響額
5. 機会損失: 運用に費やされているデジ戦工数を企画業務に転換した場合の価値

## 4. まとめ（Answer First）

- **添付の背景・目的は「IT部門の課題整理」としては良質だが、そのままでは不十分。**
- 最大の欠落は **(1) 人材・労務の構造的リスク**（採用していない／育成投資が回収できない／メンタルヘルス＝安全配慮義務）と **(2) 定量インパクト**（TCO・隠れコスト・障害時損失）、**(3) 現状維持シナリオとの対比**。
- 特に「専門人材を採用していない」という事実は、内製継続オプションを構造的に否定する最強の論拠であり、背景の第1項目に据えるべき。
- ゴール側も「コスト最適化」を「固定費の変動費化と成長投資原資の捻出」と言い換えると、Vision2030「収益力強靭化」との接続が明確になる。
