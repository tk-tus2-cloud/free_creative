# 工場「生産性向上検討」×BPRフレームの統合整理
## 工場の過去検討を資産として活かし、③(自動化)を成立させるための①②という再定義

**作成**: 2026年8月28日 意見交換向け
**入力**: 明工・生技G「生産性向上検討(自動化・自律化検討)に向けた打合せ」(2026/8/27)、BPR資料(菊池さん共有版)

---

## 0. 結論(この意見交換で持つべきスタンス)

1. **工場の過去検討は「無駄だった」のではなく、逆に本アプローチの正しさを証明している。** 工場資料にある過去3案件(チューブ供給76百万円・中間製品供給130百万円・ハンドル供給54.8百万円)はすべて「③置き換える」単独の検討であり、**投資基準(歯磨39,200千円/名・歯ブラシ44,100千円/名)またはスペース制約で成立しなかった**。①無くす・②減らすは「過去検討のやり直し」ではなく、**この死んだ③案件を投資基準の内側に蘇らせるコストダウン手段**である。
2. **検査についての工場見解「基準を見直しても人は減らない。検査機開発がクリティカル」は、方向として正しい。** 当方も検査の主打ち手は自動検査機(③)と位置づけている。基準見直しの役割はそこではなく、**工場資料自身が指摘する「全33項目検査可能な仕様」という最難関の要求仕様を、品質実績データで絞り込み、検査機開発を早く・安く・確実に成立させる前処理**である。
3. ワーディングを変える: 「ゼロベース」「棚卸し」ではなく**「過去検討の前提更新」「検査機仕様を軽くする前処理」**と呼ぶ。変わった前提(技術・賃金・目標水準・品質データ)だけを更新するのであり、工場の検討履歴を尊重した増分作業である。

## 2. 過去検討が証明していること — 「③単独では投資基準を超えられない」

工場の3つの過去案件を死因で見ると、共通構造がある:

| 案件 | 見積もり | 死因 | ①②を先に当てた場合の再評価仮説 |
|---|---|---|---|
| チューブ供給自動化 | 76,000千円(▲1名) | 投資基準39,200千円/名を超過 | 養生布抜取・定数チェック・PL反転等のサブルーチンが装置仕様を複雑化。**資材仕様・受入基準の変更でサブルーチンを消せば装置は「運ぶだけ」に単純化**→見積もり圧縮の余地 |
| 中間製品供給自動化 | 130,000千円(▲6名/2シフト) | スペース切迫で導入不可 | ②集約(複数ライン供給の統合・AMR化)でレイアウト前提ごと変える選択肢。単ライン専用機の発想を離れる |
| ハンドル供給機(31-7,8号) | 54,800千円(▲1名) | 費用対効果低 | ヒューマノイド(工場検討中)は**可搬・複数作業兼務**が本質。1台=1作業の前提を外し、供給+箱詰め+パトロールを束ねれば「1名あたり投資」の計算が変わる |

**含意**: 工場は「何度も検討して今の体制」に至ったが、その検討はすべて**現行の作業内容・資材仕様・基準を所与とした③の検討**だった。3件とも「あと一歩」で死んでいる — つまり必要なのは検討のやり直しではなく、**装置の要求仕様を軽くする前処理(①②)を足して再見積もりすること**。

## 3. 検査 — 工場見解への回答(最重要・機微)

### 工場見解は正しい。その上で役割分担を明確にする

| | 内容 |
|---|---|
| 工場見解 | 「基準を見直したところで人の数はあまり変わらず、検査機の開発・導入のほうがクリティカルに効く」 |
| 当方の立場 | **同意。検査の主打ち手は自動検査機(③)である。** BPR資料でも検査の効果の主体は③に計上している |
| 基準見直しの本当の役割 | 人を減らすことではなく、**検査機の要求仕様を絞ること**。工場資料の「全33項目検査可能な仕様で検討が必要」がそのまま要求仕様になると、開発難度・費用・期間が最大化し、過去3案件と同じ死に方(投資基準超過)をするリスクがある |

### 具体的な進め方(検査機開発の前処理として)

1. **15項目(抜き取りのみ)×品質実績の突合**(1〜2か月・投資ゼロ): 各項目の市場クレーム実績・工程内検出率・重篤度を並べる
2. 仕分け: (a)市場流出実績があり重篤 → **検査機の必須仕様**(ここに開発資源を集中) (b)発生実績が僅少・軽微 → 統計的管理(SPC)+抜き取り継続で管理できないか品質保証が判定 (c)上流の工程条件で発生源を潰せる項目 → 検査でなく工程改善で対応
3. 結果として検査機の必須仕様が33→仮に25項目前後に絞れれば、**開発は「早く・安く・確実」になり、投資基準を通る確率が上がる**
4. 並行運転(目視との検出力比較)は検査機導入時にいずれ必須になる検証であり、その準備(目視の見逃し率ベースライン測定)を先行させる

**一言で**: 基準見直しは検査機の**代替**ではなく**成立条件**。「基準か検査機か」の二択ではなく「基準検証→仕様凍結→開発」の順序の話である。

## 5. 「変わった前提」の明示(ゼロベースではなく前提更新である根拠)

過去検討時点から変わったもの**だけ**を更新する:

1. **技術**: フィジカルAI・画像AIの成熟とコスト低下。工場自身が31-7,8号でヒューマノイドを検討中 — 可搬・多能工型ロボットは「1台1作業」前提の過去見積もりを無効化する
2. **経済**: 賃上げ5%台の継続 → 投資基準の分母(1名あたり人件費の現在価値)が上昇。**過去に基準超過で死んだ案件が、同じ見積もりでも成立圏に入り得る**
3. **目標水準**: 役員期待が「115→100名」から「半減レベル」へ — 現行体制を最適とした前提条件(目標)自体が変わった
4. **データ**: 品質実績(クレーム・工程内不良)の蓄積により、検査33項目の統計的検証が過去より高い精度で可能

## 6. 意見交換の進め方(8/28)

1. **冒頭で明言する**: 「過去の検討をやり直すのではない。過去検討の見積もりとスコープアウト判断は台帳の中核資産であり、変わった前提だけを更新して再評価する」
2. **工場のスコープ候補(①供給・箱詰め/②検査)をそのまま土台として承認する** — Howから入っていること自体は問題ではない。③の候補リストとして正当
3. その上で1工程だけ演習: 例えばチューブ供給(過去76百万円)を取り上げ、「サブルーチン(養生布・定数チェック・PL反転)を仕様変更で消したら装置見積もりはいくらになるか」を一緒に概算する — ①②の価値を抽象論でなく**工場自身の案件の再評価**で見せる
4. 検査は§3の整理(基準見直し=検査機開発の前処理)を提示し、「15項目×品質実績の突合」を品質保証と工場QAの共同タスクとして提案する(1〜2か月・投資ゼロ)
5. 決めること: (a)過去NG3案件の再見積もり(①②後仕様)をクイックウィン候補としてWBSに追加するか (b)検査15項目の実績突合の担当と期限 (c)投資基準の前提更新をSCM戦略部に依頼するか
