# 生産性ボトルネック調査 推進方法(提案書)

**対象**: ライオン株式会社 オーラルヘルスケア生産(明石工場: ハブラシ植毛・ハブラシ包装・ハミガキ包装)
**目的**: 生産性のボトルネックをゼロベースで特定し、フィジカルAIに限定しない打ち手ポートフォリオ(品質基準・規定見直し含む)として効果試算まで持ち込む
**作成**: 2026年8月11日 / 戦略コンサルタント視点での推進方法提案

---

## 0. エグゼクティブサマリー

- **To-Be**は経営数値から逆引きする: Vision2030 2nd STAGE(2025〜27年、収益力強靭化: EBITDAマージン13%超・ROIC8〜9%)と生産技術KGI「一人当たり生産金額 2030年+20%」を頂点に、明石工場317名→264名(省人化53名)、植毛ライン115名→半減(役員期待)を工場・ラインレベルのTo-Beとして設定する。
- **最大のGAP**はハブラシ植毛ライン: フィジカルAI導入後も100名残る計画に対し役員期待は半減(≒57名)。**約43名分の打ち手が現計画に存在しない**。
- 43名ギャップは単一の技術では埋まらない。**「自動化」「品質基準・規定のゼロベース見直し」「工程・オペレーション改善」「工場全体最適」の4カテゴリー×9打ち手**の仮説を先に立て、検証型で調査する。
- 調査手法は三層(稼働データ/人員動態/ヒアリング)。ただし6/10デジ戦打合せで**既設カメラは即戦力にならない**ことが確認されたため、初動はワークサンプリング+調査用簡易カメラの臨時設置で立ち上げ、恒久的な人員動態解析は27年以降のテーマとする。
- **リターン**: 省人化53名≒**年2.7億円**(1人5百万円換算)+品質基準見直しによるクイックウィン**年0.3〜0.6億円**+B停止削減による能力増。投資(フィジカルAI開発費27〜29年150百万円+調査費)に対し、**3年回収圏内**。
- **26年12月までにボトルネック特定・打ち手優先順位確定**(10月中間報告)、27年からPoCと規定見直しの実行に移す。

## 5. 原因(なぜGAPが生じているか — 構造化)

1. **品質保証が「人の目」を前提に設計されている**: 検査・外観確認・長毛処理の基準が人手作業を暗黙の前提として規定され、自動化・統計化の検討対象から外れてきた。
2. **B停止を「人が吸収する」運営**: 停止原因の解析→設備・工程改善のループがなく、監視・復旧要員の張り付きが固定費化。
3. **要員数が「所与」になっている**: 既存設備を動かす前提の積み上げで設定され、妥当性を検証するデータも仕組みもない。
4. **ライン単位の部分最適**: 資材供給・搬送・段替えがライン毎に要員を持ち、工場全体での統合(AMR・多能工・応援体制)が設計されていない。
5. **規格・規定の積層**: 品質基準・SOP・記録類が過去の品質事象への対応で積み上がり、現在の技術水準(センサー・AI検査)でのゼロベース見直しが行われていない。
6. **非定型作業・多品種**: 高付加価値多品種戦略(クリニカ/システマ等)に伴う段替え・品種切替がライン効率と要員数を押し上げている。
