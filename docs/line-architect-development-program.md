# ラインアーキテクト人材育成プログラム
## 成果を出す人材を育てるための、あるべき姿/現状/GAP/解決策

**作成**: 2026年8月 / 戦略コンサルタント視点
**射程**: 明石工場ボトルネック調査(生産性ボトルネック調査 推進方法 Ver2.0)と一体運用

---

## 0. エグゼクティブサマリー

現行の育成計画(強化人材②)は**技術(ロボティクス・AI)の深度を測る1本のピラミッド**であり、予算100万円/年・対象4名程度でロボットPoC実践・ROS入門等のOff-JTを提供する設計になっている。しかし技術を深く学んだだけの人材は、**「何を解くべきか」「投資に値するか」「組織をどう動かすか」を判断できない**——これがラインアーキテクトに実際に求められる能力の中心である。

GAPの本質は「技術研修の不足」ではなく、**「構想力(基準を疑う→工程を再設計する→投資判断する→組織を動かす)を鍛える経路が存在しないこと」**。解決策は、Off-JTを廃止するのではなく**主役から補完役に降格**させ、明石のボトルネック調査そのものをOJTの主戦場とする成果駆動プログラムに組み替えることである。

対象者は**コア人材2〜4名+ベース層4〜6名**の二層設計とし、26年9月にボトルネック調査WGへ第1期生を投入、27年のフィジカルAI PoCと同期させて構想力を段階的に証明させ、29〜30年に「自分が育てた後継者がいる」状態(組織への定着)を完成条件とする。

## 1. あるべき姿(To-Be) — 2030年、成果を出すラインアーキテクトの状態

| 項目 | あるべき姿 |
|---|---|
| 人材の定義 | 技術Level2(現場適用)程度を土台に、**構想力C1〜C4(基準を疑う/工程を再設計する/投資判断する/組織を動かす)**を備え、実プロジェクトで定量成果(▲人数・億円・投資判断への採用)を出せる人材。ロボット工学の専門家(Level4 R&Dエンジニア)である必要はない |
| 人数・構成 | コア人材(自走レベル)2〜4名+ベース層(ベンダーと対話し現場適用できるレベル)4〜6名。**技術×構想力マトリクスで技術Level2〜3×構想力C3〜C4に到達した者がコア人材** |
| できること | ①現場で「この作業はなぜあるか」を基準まで遡って疑える ②改善策を複数ライン・工場全体視点で設計できる ③効果をOEE正味・ROIで定量化し、品質保証・SCM戦略部と対等にビジネスケースで対話できる ④現場の抵抗・品質懸念を越えて実行に落とし込める |
| 実績 | 明石で確立した「無くす→減らす→置き換える」の型を、包装ライン・他工場へ**自走で横展開**できている。フィジカルAI・自動検査の投資判断に、自分の分析が採用された実績を持つ |
| 組織への定着 | コア人材が**自分の後継者(第2期生)を1名以上育てている**。ラインアーキテクトが工場の恒久機能として制度化され、個人の異動・退職で消滅しない |
| KGIへの貢献 | この人材群が、植毛ライン半減(115→57名)・工場317→264名・一人当たり生産金額+20%の実行部隊そのものである |

## 2. 現状(As-Is)

既存の育成計画(強化人材②:DX人材(ロボティクス))を確認すると:

| 項目 | 現状 |
|---|---|
| 育成の軸 | ロボティクス・AI技術レベルの単一ピラミッド(Level1操作→Level2現場適用→Level3統合設計→Level4内製化)。**構想力(何を解くべきか・投資に値するか・組織を動かすか)を測る軸が存在しない** |
| 目指す姿(現行定義) | 「ロボティクス・AIの基本的なスキルを保有し、フィジカルAIを現場適用できる人材」(Level2相当)。技術要件は明確だが、成果要件(何を実現したか)の定義がない |
| 対象規模 | DXキーマン=開発/導入サイド1〜2人+現場適用サイド1〜2人(実質2〜4名)。ベース層(現場OJTでITリテラシー向上)は人数未定義 |

| 予算 | 100万円/年(4名程度) |
| 評価・進級条件 | 研修の受講・カリキュラム消化が基準。**「自分の名前で出した成果」を評価する仕組みがない** |
| 実プロジェクトとの関係 | ボトルネック調査(明石植毛)は26年8月に別途始動するが、育成プログラムとOJTとしての結合は未設計 |

## 3. GAP

| # | GAP | 影響 |
|---|---|---|
| G1 | **構想力を育てる経路が存在しない**。技術ピラミッドを上に登らせても、Level4(R&Dエンジニア)は「何を解くべきか」を判断する力の証明にはならない | 技術は使えるが、経営・品質保証と対話し投資判断を主導できる人材が生まれない |
| G2 | 対象者の**二層設計(コア/ベース)が未定義**。DXキーマン2〜4名という数字はあるが、育成レベル像(自走できるのはどのレベルか)が不明確 | 投資(100万円/年)の規模の妥当性を判断できず、育成のゴールが曖昧なまま進む |
| G3 | 育成が**実プロジェクトから切り離された座学中心**。順序も「研修→実践」であり、成果駆動の逆順(実践→不足補完)になっていない | 27年のフィジカルAI PoC開始までに、それを主導できる人材が育っていない可能性 |
| G4 | **評価基準が受講実績**であり、成果(改善案の採用、効果の実現、投資判断への貢献)に紐づいていない | 「研修を受けた人material」と「成果を出せる人材」が区別されず、昇格・登用の判断材料がない |
| G5 | **評価者が技術部門のみ**。構想力(投資判断・組織を動かす力)は品質保証・SCM戦略部でなければ測れない要素を含む | 技術評価に閉じた人材選抜になり、構想力の高い人材が見過ごされるリスク |

## 4. 解決策(How) — 育成プログラムの組み替え

### 4-1. 設計思想の転換

| | 現行 | 新設計 |
|---|---|---|
| 主役 | Off-JT(社外研修) | **明石ボトルネック調査の実プロジェクト(OJT)** |
| Off-JTの位置づけ | 育成の中心 | 実務で不足に気づいた技術を**後から補完**する役割に降格(順序: 実践が先、研修が後) |
| 評価軸 | 技術レベル(単軸) | **技術レベル × 構想力レベルの2軸マトリクス** |
| 進級条件 | カリキュラム消化 | **自分の名前で出した成果(採用された改善案・実現した効果・投資判断への貢献)** |
| 評価者 | 技術系上長 | 技術系上長+**品質保証部門+SCM戦略部**(構想力は技術部門だけで測れない) |

### 4-2. 対象者の二層設計(最初に確定すべき事項)

| 層 | 人数 | 到達目標 | 選抜基準 |
|---|---|---|---|
| コア人材 | 2〜4名 | 技術Level2〜3×構想力C3〜C4。自走でPoC設計・投資判断・展開リードができる | 現有エンジニアから、工場実務経験+分析志向を持つ人材を生技セ+工場長で選抜 |
| ベース層 | 4〜6名 | 技術Level1〜2×構想力C1〜C2。ベンダーと対話し現場適用・基準の疑問提起ができる | 明石工場の若手〜中堅から、現場のOJT対象として広く選抜 |

### 4-3. 技術 × 構想力マトリクスによる評価軸

構想力4段階(C1基準を疑う/C2工程を再設計する/C3投資判断する/C4組織を動かす)を、既存の技術4段階(Level1操作〜Level4内製化)と直交させ、育成対象者ごとに現在地と目標地点を可視化する。**コア人材の到達目標は技術軸で最上位(Level4)である必要はなく、Level2〜3×構想力C3〜C4の組み合わせ**であることを育成方針として明文化する。

### 4-4. 成果駆動フェーズプログラム(ボトルネック調査WBSと同期)

| フェーズ | 対応する構想力 | 実務スコープ | 求める成果(進級条件) |
|---|---|---|---|
| 0. 選抜・配属 | — | 台帳作成チームの一員として植毛ラインにアサイン | 担当工程の作業-規定台帳を期限内に完成(品質保証のレビュー通過) |
| 1. 実行担当 | C1 基準を疑う | 基準改定・プロセス改善チームの実務担当 | 自分が起案した改善策が1件以上、QA変更管理プロセスまたは工場の改善提案に採用される |
| 2. サブテーマリード | C2 工程を再設計する | ECRS再設計・SMED等、1テーマの責任者 | リードしたテーマで定量効果(▲X名)を出し、月次報告を自分で説明する |
| 3. PoC設計・投資判断 | C3 投資判断する | フィジカルAI・自動検査PoCの設計に参画 | 自分が設計したPoC結果が実際の投資意思決定に使われる |
| 4. 展開リード | C4 組織を動かす | 植毛の型を包装ライン・他工場へ展開するプロジェクトのリーダー | 展開先で植毛と同水準の効果を再現する |
| 5. 育成側への転換 | C4(継承) | 第2期生のメンター。工場の恒久組織に定着 | 自分の下から次のラインアーキテクトを1名以上育てる |

### 4-5. Off-JTの再配置(補完材として維持)

既存の社外研修(工程自動化ワークショップ・ロボットPoC実践・ROS入門・チューニング研修、予算100万円/年)は廃止せず、**各フェーズで実務上ぶつかった技術的不足を埋めるためだけに使う**。フェーズ1〜2はロボット基本操作・作業分解スキル、フェーズ3〜4はPoC設計・システム統合の研修を必要に応じて配置する(時期は固定カリキュラムでなく実務の必要に応じて可変)。

## 7. 本プログラムの位置づけ(ボトルネック調査との一体性)

本育成プログラムは、明石ボトルネック調査(生産性ボトルネック調査 推進方法 Ver2.0)のWBSと**別のプロジェクトではなく、同じ実務の裏面**である。調査側が「作業を無くす→減らす→置き換える」を実行するプロセスそのものが、育成側の構想力C1〜C4を証明する舞台になる。したがって本プログラムの成否は、独立した研修予算の増減ではなく、**調査WBSのSTEP①②③の進捗と一致して測られるべきである**。
