## 2. 中核となる考え方（3つだけ覚えればよい）

**① 新卒には「完成品」ではなく「変わりにくい素地」を求める（4層モデル）**

| 層 | 例 | 入社時 |
|---|---|---|
| 知識 | 会計・財務、フレームワーク、高度なIT専門性 | あればよし（教えれば身につく） |
| スキル | 構造化力、資料作成、提言力、合意形成・調整力 | あればよし（実務で育つ） |
| 思考の癖 | 「なぜ？」と考える、要素を分けて話す、相手に合わせて伝える | **見る**（変わりにくい） |
| 気質 | 知的胆力、誠実さ、裏方の喜び、テクノロジーへの好奇心 | **見る**（ほぼ変わらない） |

**② デジタルの素地だけは例外として入社時に問う**
データ分析・統計・ITの基礎は大学までに学ぶ機会が広くある。だから「学んでこなかった」こと自体が関心の低さのシグナル。メッセージは「**専攻は問わない。ただしデジタルに自ら触れてきた事実は問う**」。

**③ 素地は「行動の事実」で見極める**
自己申告ではなく、過去の行動（やり切った経験・異論を言えた経験）と、その場で試せる小課題（「分析内容を専門外の人に説明して」「生成AIをどう使ってる？」）で判別する。

## 3. チーム別の活躍像（要約）

| | 戦略企画室 | DX推進チーム |
|---|---|---|
| 本質 | **決める**（意思決定・資源配分・ガバナンス） | **変える**（現場変革・PL成果の刈り取り） |
| 目指す姿 | 経営とデジタルの翻訳者。「やらないこと」を決めさせ、摩擦を恐れず追い切る | 現場に入り込み、相手のメリットで巻き込み、導入でなく成果まで刈り取る |
| 思考の癖の中心 | 構造化と数字 | 「そもそも」（課題設定）と段取り（推進） |
| 気質の本丸 | 知的胆力（規律の担い手） | 現場への敬意 × 巻き込み（共創の担い手） |

※③マインドは両チームとも部の「DX実践指針」（成果の定義／妥協の排除／巻き込み方／Quickwin／責任の明確化／伴走の覚悟）を新卒レベルに翻訳したもの。

## 4. Kick-off MTG資料へのレビュー指摘（要約）

| # | 指摘 | 重要度 | 対応状況 |
|---|---|---|---|
| 1 | 28卒人物像が抽象的すぎて選考基準として機能しない（平均化の罠） | 高 | **対応表を作成済み**（下記5-①） |
| 2 | 合格出し人数（歩留まり）の設計が丸ごと抜けている | 高 | **シミュレーション作成済み**（下記5-②） |
| 3 | 本命ターゲット（外資IT併願層）と12月内々定のスケジュールが不整合 | 高 | 要意思決定：本命層に張るか、準ターゲットで勝つか |
| 4 | 人物像→評価設計の接続が次回送り | 中 | 対応表で前倒し可能 |
| 5 | 共通項に落ちなかった各T固有要件の使い途が未定義 | 中 | 「共通項=選考基準／固有項=配属基準」の一行宣言を推奨 |
| 6 | グリップ施策にKPI・効果測定がない | 中 | 辞退予兆の検知（定期パルス）を上位に置く |
| 7 | 体裁（P9欠番、P10「静観」の説明性、P11レイアウト崩れ等） | 軽微 | 修正のみ |

## 5. レビュー対応で作成したツール

**① 人物像×選考ステップ対応表**：9つの評価要素それぞれに主評価（◎）ステップを1つだけ割り当て、確認方法を行動レベルで定義。技術面接=コアスキル4要素、人事面接=マインド3要素、最終=志望度（見極め2:惹きつけ8）。

**② 歩留まりシミュレーション**：着地3名に対し**3名ちょうどの合格出しは承諾率70%でも未達確率66%**。推奨は「**4名内々定＋補欠1〜2名（繰上げ順位付き）**」。超過1名のコスト＜欠員のコスト（キャリア補填の不確実性・第2クールの現場負荷）のため。

## 6. 残る意思決定事項（宿題）

1. **主戦場の決定**：本命層（外資IT併願）に張るか、準ターゲット（文理不問・構造化/巻き込み型）で勝つか → スケジュール・訴求・グリップ全てがこれに従属
2. **27卒の承諾率実績・辞退理由の確認** → シミュレーションのどの列で読むかが決まる
3. **超過1名の翌年枠通算ルールの事前合意** → 合意できれば「4名+補欠」で確定
4. **学部・院の同一基準の決着**（ITテストの専門性加点の扱いとセット）
5. **補欠運用の設計**（人事部協議）
