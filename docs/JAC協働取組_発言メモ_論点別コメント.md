# フリーディスカッション 発言メモ(論点別・箇条書き)

2026年7月30日 経営執行会議 懇談事項 — 資料P20 論点1〜4への発言用

---

## 前提(冒頭に置く総括)

- 成功の物差しは株価・企業価値。JACの対価は株価上昇のみであり、検証は活動量ではなく「株価=利益×評価倍率」の分解で行うべき
- 利益のレバーは効いた: 2割超の増益。協働開始前は減益・株価低迷のトレンドであり、JACがいなければ劣後はさらに深かった — これは認めるべき成果
- しかし株価は+7%にとどまり、市場(TOPIX+51%)に約▲44pt劣後。業界内(花王ほぼ横ばい・ユニ・チャーム軟調・資生堂大幅安)では見劣りしないが、それは「業界ごと市場から置いていかれている」ことの裏返し
- 原因は評価倍率: 目標29倍に対し現在16.1倍と、起点の約19倍からむしろ低下(花王23.3倍)。利益改善の果実を倍率低下が食い潰した
- 結論: 利益のレバーは効き、倍率のレバー(=ヘルスケア成長企業としての再評価)が未着手。本日は「共通認識化」ではなく、この軌道修正を「責任者・期限・数値」まで決める場にすべき

## 論点1: JACとの取組の何を変えていくべきか

- JACの関与先を「利益改善」から「倍率を動かす領域」へ移す。テーマの選別基準は「評価倍率に効くか」の一点
- 集中すべきは3テーマ: ①オーラルケアを軸とするヘルスケア成長戦略 ②海外事業の収益構造の立て直し(合弁マージンの抜本見直しを含む) ③売却・撤退を含む事業ポートフォリオの入れ替え — 2年間未着手の資本配分議論を初めて正式議題に載せる
- テーマを絞ると同時に、会議体・報告も削る。活動の総量ではなく関与の密度を上げる
- 助言を受けて検討する関係から、決めた戦略を完遂させる関係へ。議題設定権は当社が持ち、戦略に合わない持込み案件・一度否決した案件の再提示は入口で断る
- 協働の公式KPIに「花王との倍率差」「ヘルスケア企業群との倍率差」を追加する。倍率で測らない限り、再評価の進捗は測れない

## 論点2: 自社内で変えていかなければいけないことは何か

- この2年の最大の教訓: 外部の力は、当社側に受け皿(責任者・権限・予算)がある領域でしか機能しない。OHC成長戦略(分科会4)の中止はJACの力不足ではなく、当社の未決定の問題
- 従って最優先は、ヘルスケア成長戦略を「責任者名・委譲権限・専用予算・競争戦略(どの領域で誰に勝つか)」を明記して再始動すること。8月取締役会には体制図まで持ち込む
- 「17%達成のためにどこまで踏み込み(売却・撤退・人員含む)、何を守るか」の線引きを、執行任せにせず取締役会決定として明文化する。線引きのない目標は、市場には約束ではなく願望に見える — 倍率16.1倍はその市場の採点
- 27年目標の先(30年20%・次世代ヘルスケア)を設計する担当を、現行の執行体制から切り離して置く。全員を目先の目標に張り付ける体制は、次の成長を作る人間をゼロにする
- 推進部門による自己検証は「成果も課題もあった」に着地しやすい。市場対比・同業対比の倍率という外部の目盛りと、社外取締役の視点を検証に組み込む

## 論点3: JACと何を合意していく必要があるか

- 最優先は出口の設計。成功・失敗の基準(利益KPI+倍率KPI)と、達成/未達それぞれの場合に協働を「継続・縮小・終了」する判断基準を、事前に文書で合意する
- JAC保有株の売却について、時期・方法・市場への説明手順を平時に設計する。「あるべき株価2,600円」を公言する投資家が存在する以上、無防備な売却局面は当社が最も攻撃されやすい瞬間になる
- 出口の透明化は防御であると同時に、「いつ売られるか分からない」という株価の重石を外す — それ自体が倍率対策になる
- 2,600円との差分の要因分解(マージン・成長・倍率・資本配分)を両社共同で作成し、IRストーリーの背骨にする。資本市場出身者を擁するJACに最も期待すべき成果物
- 運営規律 — 情報管理(事前承認のない報道)、担当者の継続性、否決案件の再提示禁止 — を紳士協定ではなく合意文書にする

## 論点4: 変えなくてもいいこと(維持すること)はあるか

- 利益を2割動かした経営基盤は維持する: 月次業績管理サイクル(月2回転)、BU制による権限委譲(中東情勢への機動対応で実証)、決算・開示前に外部視点のレビューを通すプロセス、目標から逆算する文化
- これらは同業他社に対する経営基盤の優位であり、解体しない — ただし条件は26年度中の自社移管(内製化)。JACの存在を前提に回っている限り、退出と同時に失われる。「JACがいなくても回る」ことを確認して初めて「維持」と言える
- 維持の決定と廃止の決定は必ずセットで示す: この2年で増えた会議体・報告を棚卸しし、やめるものを明示する。実行部門の疲弊と取組の形骸化(リスク1)への最も有効な手当

## 締め(発言の最後に)

- 8月取締役会に持ち込むべきは検証結果ではなく4つの決定: ①成長戦略再始動の体制 ②構造改革の線引き ③JACの出口条件 ④内製化の期限+廃止リスト
- この2年で「外部の力を借りれば利益は動く」ことは証明された。次の1年半で証明すべきは「利益の改善を市場の評価に変える意思決定が、当社自身にできること」。2nd STAGEの残期間に、検証のための検証を繰り返す時間はない
