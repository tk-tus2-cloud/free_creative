## 0. エグゼクティブサマリー

1. **前提認識**: SSBJ義務化により非財務情報は「任意のレポート」から「有価証券報告書での法定開示・第三者保証対象」へ転換する。当社のAs-Isは、34サイトのExcel・メールによるバケツリレー、承認ワークフロー・確定ロック・変更履歴・閲覧権限の全工程での欠如、有報向けフローの未構築という状態であり、2028年1月〜12月のデータ集計本番から逆算して**2027年中の基盤稼働が必須**である。
2. **基本方針**: 要求整理は「守り(法定開示対応=インプットの極小化と強固なガバナンス)」と「攻め(非財務の財務化=アウトカムの最大化・PBR向上)」の2軸を、**同一のデータ基盤・同一の要求体系の中で**設計する。守りのために集めるデータ(活動量・証憑・組織・製品)こそが、攻めの分析(インパクト評価・シミュレーション)の原材料であり、二重投資・二重入力を許さない。
3. **攻めの中核**: 世の中の先進企業(エーザイ柳モデル、ユニリーバ、コルゲート、フィリップス、サントリー、SAP等)が示す通り、非財務が財務に跳ね返る「因果パス(インパクトパス)」を定義し、KPIとして計測・開示・経営管理することが企業価値(PBR)向上の王道である。当社は**「オーラルヘルスによる健康・医療費インパクト」と「使用時の節水・CO2削減インパクト」**という、事業と一体化した独自テーマで先行できるポジションにある。
4. **要求整理の骨格**: 「守り×攻め」×「業務要件・機能要件・システム要件」の6象限で網羅的に整理した(本書4〜6章)。RFPには守り要件を必須(MUST)、攻め要件を段階導入(PHASED)として格納し、ベンダー評価軸に反映する。

## 1. 前提整理 — As-Is課題とSSBJ要求のギャップ構造

### 1.1 As-Isの構造的課題(As-Is詳細業務フローより)

| 工程 | As-Isの実態 | 守り上のリスク | 攻め上の機会損失 |
|---|---|---|---|
| ①現場作業・データ発生 | 34サイトの検針・請求書・伝票、海外は単位・通貨バラバラ、委託会社の実データは1社のみ | 網羅性・正確性の欠如、Scope3の実測性欠如 | 製品・拠点別の粒度が粗く分析に使えない |
| ②データインプット | エコアシスト手入力+投入用Excel+SAPからの属人的手動抽出 | 入力ミス・抜け漏れ、抽出条件の属人化 | 月次より細かい鮮度のデータが存在しない |
| ③収集(事務局ハブ) | ESG企画室が全領域のハブ。督促・確認・修正依頼がすべて個別メール | 承認行為・証跡なし(履歴はメール記録のみ) | 事務局が収集作業に忙殺され分析工数ゼロ |
| ④算定・集計 | Excelコピペ集計、係数手動更新、Scope3は二次データ中心、製品LCAは属人R言語システム | 算定ロジックのブラックボックス化、監査トレース不能 | 削減努力が数値に反映されず、施策効果が測れない |
| ⑤検証・統制 | SGSサンプル検証(S1/2=年2拠点、S3=Cat1,11,12のみ)、指摘104件をExcel台帳管理 | 全量保証(合理的保証への将来移行)に耐えない | 指摘対応に数週間、経営の意思決定に使う余力なし |
| ⑥開示 | 統合レポート年1回・後追い。有報向けフローは**未構築** | 有報同時開示(SSBJ)に物理的に間に合わない | 開示が「守りの作業」で終わり、IR・事業に還流しない |

**統制ギャップ(SSBJ最大論点)**: 承認WFなし/修正は上書き=履歴なし/確定・ロックなし/閲覧権限管理なし。

### 1.2 SSBJが求める変化(構想資料より)

| 項目 | As-Is | SSBJ後 |
|---|---|---|
| 開示場所 | 統合報告書(任意) | 有価証券報告書(法定) |
| 計算範囲 | 自社拠点中心 | 原材料〜使用・廃棄までの全バリューチェーン(Scope3含むフル開示) |
| 記載内容 | 取り組みの紹介 | 4つの柱(ガバナンス/戦略/リスク管理/指標と目標)+財務的影響(リスクと機会)の試算 |
| データの質 | 概算値 | 第三者保証に耐えうる証跡のある数値 |
| タイミング | 年1回後追い | 決算数値との同時開示(有報同期) |

### 1.3 時間的制約(クリティカルパス)

- 当社適用義務は2030年〜目安(花王は2029年)。ただし**2029年3月期開示を目指す場合、2028年1〜12月データが本番**。
- 逆算すると**2027年中にシステム導入完遂**が必須であり、「戦略・方針の骨子確定を待ってから要件定義」では間に合わない。
- したがって本要求整理は、**戦略策定と並行しても破綻しない「データ統制の骨格(守り)」を先に固定**し、戦略確定に応じて変わり得る「活用の仕掛け(攻め)」を拡張可能な形で織り込む、という二層構造をとる。

## 2. 先進企業ベンチマーク — 非財務の財務化に関する示唆

世の中の先進企業の取り組みを「①因果の実証」「②事業との一体化」「③基盤・仕組み化」「④ガバナンス連動」の4類型で整理する。(各社公表情報に基づく要約)

### 2.1 類型①: 非財務→財務の因果を統計的に実証する

| 企業 | 取り組み | 当社への示唆 |
|---|---|---|
| **エーザイ(柳モデル)** | ESG KPI(人件費、研究開発費、女性管理職比率、健診受診率等)とPBRの遅延相関を重回帰分析で実証。「人件費投入を1割増やすと5年後のPBRが約14%向上」等、非財務投資が数年遅れで企業価値に浸透することを開示し、IRの中核に据えた | 当社の非財務KPI(オーラルケア習慣者数、節水貢献量、エンゲージメント等)×財務指標(売上・営業利益率・PBR)の時系列データを基盤に蓄積し、**遅延相関分析を再現可能にするデータ設計**が必要 |
| **ハーバードIWAI/Value Balancing Alliance(BASF等)** | 環境・社会インパクトを貨幣換算し「インパクト加重会計」として損益に統合。BASF「Value to Society」は事業が社会に生む正負の価値を金額表示 | 健康・節水インパクトの**貨幣換算ロジック(単価マスタ: 医療費削減単価、水の社会的価値等)をシステムのマスタとして持つ** |
| **ダノン** | 炭素調整後EPS(carbon-adjusted EPS)を開示し、脱炭素と株主価値を同一言語で説明 | 炭素税・内部炭素価格シミュレーションを財務指標(EPS/営業利益)に接続する機能要件 |

### 2.2 類型②: サステナ・健康テーマを事業成長と一体化する

| 企業 | 取り組み | 当社への示唆 |
|---|---|---|
| **ユニリーバ** | 「サステナブル・リビング・ブランド」が他ブランドより約7割速く成長し、全社成長の75%を牽引と開示。パーパス起点ブランドの成長寄与を定量提示 | 「健康・環境貢献型製品」の売上構成比・成長率を**製品マスタにフラグを立てて自動集計**できる設計(グリーン/ヘルス売上比率のKPI化) |
| **コルゲート・パルモリブ** | オーラルヘルス教育「Bright Smiles, Bright Futures」で累計10億人以上の子どもにリーチ。歯みがき時の節水啓発「Save Water」をブランドキャンペーン化し、使用時インパクトをブランド価値に転換 | 「リーチ人数×行動変容」を**アウトカムKPIとして継続測定**し、ブランド投資(広告宣伝費)との関係を分析できるデータ粒度を確保 |
| **フィリップス** | 「改善した人々の生活(Lives Improved)」を全社KGI(25億人/2030年)とし、製品出荷・臨床データから算定するメソドロジーを公開。グリーン売上比率も管理 | 「習慣づくり貢献人口」等の当社KGIについて、**算定メソドロジーの文書化・監査可能性**をシステム要件に含める |
| **P&G** | 洗濯の低温化・すすぎ削減キャンペーンで使用時CO2(Scope3 Cat11)削減を消費者価値・ブランド価値と接続 | 当社の「すすぎ1回」等の使用時インパクトはScope3 Cat11削減と節水貢献の両方に直結する**最重要の攻めテーマ** |

| 企業 | 取り組み | 当社への示唆 |
|---|---|---|
| **SAP(Green Ledger)** | カーボンを取引(トランザクション)レベルで会計と同じ台帳構造で記録する「財務級」カーボン会計を提唱・自社実践 | ERP(SAP S/4HANA)との**取引レベル連携**を将来拡張として想定したインタフェース要件 |
| **マイクロソフト** | 2012年から社内炭素課金(internal carbon fee)を運用し、部門損益に反映。カーボンネガティブ目標 | 内部炭素価格を**部門・製品別の管理会計に反映**できる配賦・レポーティング機能 |
| **花王(競合)** | アクティビスト(オアシス)からScope3実測値ベース算定・有報同期の透明性・非財務KPIと役員報酬の連動を追及されている | 同じ追及を受けても**システムで客観的に証明できる**ことが守りの到達水準。かつ先回りして攻めに転じる |

### 2.4 類型④: ガバナンス・報酬に連動させる

| 企業 | 取り組み | 当社への示唆 |
|---|---|---|
| **欧州大手(ユニリーバ、ダノン、シェル等)** | 役員報酬にESG KPI(GHG削減、DE&I等)を10〜25%程度組み込み | 非財務KPIの**実績確定値(監査済み)を報酬委員会へ供給する**業務プロセス・データ確定機能 |
| **エーザイ・丸井等(国内先進)** | 統合報告で非財務KPIと企業価値の接続ストーリーを取締役会レベルで議論 | 取締役会・サス協議会向けの**定型モニタリングパッケージの自動生成** |

**ベンチマーク総括**: 先進企業に共通するのは、(1) 非財務KPIを財務と同じ台帳・同じ統制で管理する、(2) 因果パス(ロジックモデル)を明示して貨幣換算・統計検証する、(3) 製品・ブランド単位まで落として事業成長と接続する、(4) 報酬・資本市場対話に組み込む — の4点。当社の要求整理はこの4点を「攻め要件」として構造化する。

## 3. ライオンが狙うべきテーマ体系 — 非財務→財務の因果パス

### 3.1 テーマ選定の考え方

当社のパーパス(より良い習慣づくり)・事業ポートフォリオ(オーラルケア、衣料・住居用洗剤、ハンド・ボディソープ、薬品、海外アジア事業)と、SSBJ/ISSB・TNFD等の開示要請、資本市場の関心(PBR・資本コスト)の交点から、**「守りの土台1つ+攻めのテーマ6つ」**を設定する。

```
[攻め] T1 オーラルヘルス  T2 水  T3 気候・脱炭素  T4 資源循環  T5 人的資本  T6 ガバナンス・報酬連動
                     ↑ すべてのテーマが共通の因果パス管理・貨幣換算・統計検証の仕組みに乗る
[守り] T0 財務級非財務データ基盤(SSBJ/有報同期・第三者保証・グローバル統制)
```

### 3.2 T0(守りの土台): 財務級非財務データ基盤

- **狙い**: SSBJ有報同時開示・第三者保証への確実な対応。花王がアクティビストに追及されている「Scope3実測値」「有報同期」「監査トレース」を、システムで客観的に証明できる状態。
- **財務への跳ね返り**: 開示遅延・訂正・グリーンウォッシュ疑義によるレピュテーション毀損の回避(資本コスト上昇の防止)、集計工数40〜60%削減、開示リードタイム1/7、監査対応費用の抑制。

### 3.3 T1(攻めの本丸): オーラルヘルス — 「予防歯科の習慣化」を財務価値に変える

- **ロジックモデル(因果パス)**:
  - インプット: オーラルケア製品・サービスの開発/マーケ投資、学校・自治体・歯科との予防啓発活動
  - アウトプット: 製品浸透(販売本数・利用者数)、啓発リーチ人数、適正な歯みがき習慣者数(行動変容)
  - アウトカム: う蝕・歯周病の減少(DMFT指数等)、口腔機能の維持(8020達成率)、全身疾患(糖尿病・誤嚥性肺炎等)リスクの低減
  - 社会インパクト: 歯科医療費・関連医療費の削減額(貨幣換算)、健康寿命の延伸、QALY改善
  - **財務リターン**: 予防歯科市場の拡大と当社シェア・単価向上、ブランドエクイティ向上(プレミアム価格受容)、行政・保険者・企業健保との連携ビジネス(B2B2C)創出、ESG評価向上を通じた資本コスト低減 → 売上・利益・PBR
- **追い風**: 国民皆歯科健診の政策議論、健康経営の普及(歯科健診・オーラルケアは生産性・プレゼンティーズムと関連)、アジア新興国の口腔衛生市場成長。
- **KPI例(KGI→KPI→ドライバ)**:
  - KGI: 習慣づくり貢献人口(オーラルケア)、オーラルヘルスインパクト貨幣換算額(円)
  - KPI: 適正歯みがき習慣者数、啓発プログラムリーチ数・行動変容率、予防歯科関連売上構成比、当社製品利用者の口腔健康指標(共同研究・実証データ)
  - ドライバ: 製品別販売数量、地域別浸透率、歯科・自治体・健保との連携件数
- **貨幣換算ロジック(例示)**: 習慣化人数 × 一人当たり年間歯科医療費削減単価(疫学研究・共同実証から設定) = 医療費削減インパクト。単価は外部監修を得てマスタ管理し、算定メソドロジーを文書化(フィリップス方式)。

### 3.4 T2: 水 — 「使用時の節水」を製品競争力とリスク管理の両面で価値化

- **ロジックモデル**: すすぎ1回洗剤・時短すすぎ製品の浸透 → 家庭の洗濯・すすぎ水量の削減(節水貢献量m3) + 給湯エネルギー削減(使用時CO2=Scope3 Cat11削減) → 消費者の水道・光熱費削減(円換算で訴求) + 水ストレス地域(アジア展開国)での社会価値 → 選好・シェア向上、Scope3目標達成、TNFD/CDP Water評価向上 → 売上・資本コスト。
- **リスク面**: 操業拠点・サプライチェーンの水リスク評価(WRI Aqueduct等の外部データ接続)、取水・排水管理(TNFD対応)。
- **KPI例**: 節水貢献量(m3/年)、節水型製品売上構成比、使用時CO2削減量(t-CO2)、水ストレス地域での取水削減率、ウォーターバランス(涵養・還元 vs 取水)。

### 3.5 T3: 気候・脱炭素 — 「守りのGHG算定」を「攻めのCFP・シミュレーション」へ

- **ロジックモデル**: Scope1/2/3のフル算定(一次データ化) → 製品別カーボンフットプリント(CFP、ISO14067準拠)の即応開示 → B2B取引先のCFP要請への対応による受注維持・拡大、環境価値訴求 → 炭素税・カーボンプライシングの財務影響シミュレーション → 脱炭素投資の最適化(限界削減費用カーブ)。
- **KPI例**: Scope1/2/3排出量(一次データ比率)、CFP算定済みSKU比率、CFP要請への回答リードタイム、内部炭素価格適用範囲、削減投資のIRR。

### 3.6 T4: 資源循環・プラスチック

- **ロジックモデル**: 詰替・付替製品比率、再生プラ・バイオマス比率の向上 → 容器包装コスト・規制対応コスト(EPR等)の低減、リサイクルインフラ(店頭回収・水平リサイクル)の共創 → ブランド選好・流通からの評価 → 売上・コスト双方に寄与。
- **KPI例**: 詰替率、プラ原単位、再生材使用率、回収スキーム参加店舗数。

### 3.7 T5: 人的資本・健康経営

- **ロジックモデル**: 従業員の健康(自社製品を活用した社内オーラルケア含む)・エンゲージメント・DE&I投資 → 生産性向上(プレゼンティーズム改善)・離職率低下・イノベーション創出 → 営業利益率・PBRへの遅延効果(柳モデル型の社内実証)。自社実証データはT1の対外エビデンスにも転用可能(「自社従業員での効果実証」)。
- **KPI例**: エンゲージメントスコア、健診・歯科健診受診率、女性管理職比率、人的資本ROI、労働災害度数率。

### 3.8 T6: ガバナンス・報酬連動

- **ロジックモデル**: 非財務KPIの確定値(監査対応済み)を役員報酬・事業部評価に連動 → 実行力の担保を資本市場に証明 → アクティビスト対抗力・ガバナンス評価向上 → 資本コスト低減。
- **KPI例**: 報酬連動対象KPIの達成率、非財務KPIの保証取得範囲、取締役会でのサステナ議題比率。

### 3.9 テーマ×財務接続の統合管理(共通の仕掛け)

全テーマ共通で、以下を「攻めの共通機能」として基盤に実装する:

1. **ロジックモデル管理**: 各テーマの因果パス(インプット→アウトカム→財務)をマスタとして定義・版管理
2. **貨幣換算エンジン**: 換算単価マスタ(医療費削減単価、水の社会的価値、内部炭素価格等)×アウトカム実績で自動換算
3. **統計検証(柳モデル型)**: 非財務KPIと財務指標(セグメント売上・利益率・PBR)の時系列相関・遅延効果分析
4. **統合KPIツリー**: KGI(PBR・企業価値)→財務KPI→非財務KPI→現場ドライバの分解と、目標・実績・予測のギャップ管理

## 8. KPIツリー(例示) — 非財務→財務の接続

```
企業価値(PBR・資本コスト)
├─ 財務KPI: 売上成長率/営業利益率/ROIC/EPS
│   ├─ ヘルス・グリーン売上構成比(T1〜T4) ← 貢献型製品売上
│   ├─ CFP対応による受注維持・拡大額(T3) ← CFP回答SLA・算定SKU比率
│   ├─ コスト: 集計工数▲40〜60%、監査費用抑制、炭素税影響(シナリオ)
├─ 非財務KGI
│   ├─ T1: 習慣づくり貢献人口/オーラルヘルスインパクト額(医療費削減換算)
│   │      ← 適正歯みがき習慣者数 ← 啓発リーチ×行動変容率、製品浸透
│   ├─ T2: 節水貢献量(m3)/使用時CO2削減量 ← 節水型製品売上比率
│   ├─ T3: Scope1+2、Scope3(一次データ比率)、CFP算定SKU比率
│   ├─ T4: 詰替率・再生材使用率・プラ原単位
│   ├─ T5: エンゲージメント・健診受診率・女性管理職比率(→利益率への遅延効果を検証)
│   └─ T6: 報酬連動KPI達成率・保証取得範囲
└─ 統計検証(柳モデル型): 非財務KPI→数年遅れの財務効果を年次で回帰分析し、IRで開示
```

守りのROI(構想資料の試算): 集計業務工数40〜60%削減(人件費換算で年間数千万円規模)、開示リードタイム1/7、監査対応・制度追随コストの抑制。攻めのROI: 資本コスト低減(PBR向上)、サプライチェーン排除リスク回避(受注維持・拡大)、人材採用・資金調達への好影響。

## 9. RFP・ベンダー評価への反映

1. **要件の格納**: 本書の FR-D(守り機能要件)を機能要件回答書(必須/推奨区分付き)として、FR-O(攻め)を「段階導入ロードマップへの対応方針」として、SR(システム要件)を非機能要件書としてRFPに格納する。
2. **評価軸(例)**: ①守り要件の標準機能カバー率、②法改正追従のロードマップと実績、③監査法人対応実績(保証取得支援)、④攻め要件(CFP・シミュレーション・BI接続・データエクスポート自由度)の対応力、⑤グローバル対応(多言語・多通貨・海外サポート)、⑥総保有コスト(アカウント追加・係数更新・改修の追加費用構造)、⑦導入・定着支援体制。
3. **実機検証必須項目**: 複数階層ワークフロー、係数一括更新(再計算ログ)、証憑添付〜監査証跡のドリルダウン、CSV一括入力、進捗管理・自動督促、ダッシュボード。
4. **契約反映**: Fit&Gap結果・データエクスポート権・AI学習への自社データ不使用・SLA・保存年限を契約書へ明記。

## 10. リスクと成功要因

| リスク | 対応(成功要因) |
|---|---|
| 戦略未確定のままシステム先行 → 手戻り | 「統制骨格=不変」「KPI・換算=可変マスタ」の二層設計(7章)。四半期同期レビュー |
| 現場の入力負荷増 → データが集まらない | 自動連携・OCR優先で入力を「減らす」設計。進捗可視化・督促自動化。教育・FAQ・現地語対応 |
| Scope3一次データ化が進まない | 支出額上位サプライヤーからの段階展開、サプライヤーポータルでの負荷軽減、購買部門との共同KPI |
| 攻めテーマが「開示のための開示」に留まる | ロジックモデルの経営承認(BR-O-01)、報酬・予算への組込(BR-O-02/12)で実行を担保 |
| 健康アウトカムの因果立証が困難 | 共同実証(アカデミア・自治体・健保)の設計、社内実証(T5)の先行、メソドロジー文書化と外部監修 |
| ベンダーロックイン・改修コスト膨張 | データエクスポート自由度・ノーコード設定(SR-01/04)を評価軸・契約に明記 |
| 属人化の再発 | R言語ツール等の計画的廃止、システム上の手順・権限・ログで組織知化 |
